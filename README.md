# AmdjedBelgacem/homebrew-tap

Homebrew casks for [Notchisland](https://github.com/AmdjedBelgacem/Notchify),
the MacBook notch as a Dynamic-Island-style surface for coding agents, music,
calls and your day.

```bash
brew tap AmdjedBelgacem/tap
brew trust AmdjedBelgacem/tap   # newer Homebrew asks before loading third-party taps
brew install --cask notchisland
```

Upgrade with `brew upgrade --cask notchisland`. Releases are not notarized yet:
the first launch may need a right-click › Open.
